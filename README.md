# NatureNest 🌿

A luxury bungalow booking platform offering immersive accommodations and convenient booking services in the scenic highlands of Cameron Highlands, Malaysia.

## 🌄 Overview

**NatureNest** is a modern, full-stack web application designed to provide a premium, nature-inspired bungalow booking experience. Users can browse luxury bungalows, check availability, and easily book through a beautifully designed, user-friendly interface.

## ✨ Features

* Google Authenticated Login

* Browse Luxury Cabins, View Detailed Descriptions and Images

* Date-Based Interactive Booking System

* Real-Time Availability Check

* Booking Management System

* Secure User Routing

* Responsive User Interface for All Devices

* Clean, Natural User Interface

## 🛠 Technology Stack

### Frontend

* Next.js (React Framework)

* Tailwind CSS

* JavaScript (ES6+)

### Backend/Service

* Supabase (Authentication & Database, Google OAuth Authentication)

* PostgreSQL

* RESTful/API Integration

### Deployment

* Vercel

## 📌 Core Functionality

* Secure Authentication Process

* Cabin Listing and Filtering

* Create and Cancel Bookings

* Dynamic Pricing/Booking Calculation

* User Dashboard for Managing Bookings
